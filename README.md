# MindCare Agent – Agentic AI for Mental Health Awareness & Suicide Prevention

An empathetic, proactive multi-agent AI system built with **IBM Bob**, **IBM Cloud**, and **IBM Granite** using **Retrieval-Augmented Generation (RAG)** to provide mental health awareness, early distress detection, stress peak forecasting, and consent-based human escalation.

## Key Features
- **Wellbeing Dashboard:** Tracks daily mood index, stress trends, and preventive coping milestones.
- **Empathetic AI Chat:** Offers compassionate, RAG-grounded conversational support and quick grounding exercises.
- **Mood & Distress Journal:** Analyzes check-in entries to detect early distress cues and recommend self-care actions.
- **Consent-Driven Escalation:** Connects users to 24/7 crisis helplines, counselors, or trusted contacts with explicit user consent.
